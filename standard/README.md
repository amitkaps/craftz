# Standard

The files the standard is checked against, laid out as each repository has them. The rules in [src/rules.ts](../src/rules.ts) read them, and a rule's fix copies from them, so there's one copy of each.

They came from ship when it froze, and change here now. [docs/standard.md](docs/standard.md) says what each rule asks for, and [package/](package/) holds the files only a package copies.
